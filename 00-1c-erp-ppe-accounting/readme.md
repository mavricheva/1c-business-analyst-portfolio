# Автоматизация учёта спецодежды и спецоснастки в 1С:ERP

## Описание проекта

Проект посвящён подготовке проектной документации для автоматизации
учёта спецодежды, спецоснастки и инвентаря в 1С:ERP.

Решение предназначено для контроля выдачи ТМЦ сотрудникам, возврата
на временное хранение на период отпуска и повторной выдачи тех же
физических экземпляров по инвентарным номерам.
## Цели проекта

- Отказаться от разрозненного учёта в Excel и бумажных карточках.
- Повысить прозрачность складских и бухгалтерских операций.
- Снизить риск ошибок при выдаче и возврате ТМЦ.
- Обеспечить контроль временного хранения без прерывания срока эксплуатации.
- Автоматизировать формирование личной карточки учёта выдачи СИЗ.

## Моя роль

1С-аналитик / бизнес-аналитик.

В рамках проекта я:

- подготовила документацию бизнес-требований (BRD);
- разработала реестр функциональных и нефункциональных требований;
- описала проектное решение и объекты метаданных в ЧТЗ;
- спроектировала процесс временного хранения ТМЦ;
- подготовила требования к ролям и правам доступа;
- разработала программу и методику испытаний;
- подготовила пользовательскую инструкцию;
- разработала шаблон личной карточки учёта выдачи СИЗ.

## Функциональность решения

- Выдача спецодежды, спецоснастки и инвентаря сотрудникам.
- Индивидуальный учёт ТМЦ по инвентарным номерам.
- Автоматическое создание операции временного хранения на основании документа «Отпуск».
- Оформление сдачи ТМЦ на временное хранение.
- Повторная выдача ранее сданных физических экземпляров.
- АРМ кладовщика для работы с операциями хранения.
- Отчёт «ТМЦ на временном хранении».
- Электронная и печатная личная карточка учёта выдачи СИЗ.
- Учёт операций по организации, складу, сотруднику, номенклатуре и количеству.

## Архитектура решения

| Объект | Назначение |
|---|---|
| Документ «Отпуск» | Основание для создания операции временного хранения |
| Документ «Операция временного хранения» | Сдача и выдача ТМЦ |
| Регистр накопления «Движение временного хранения ТМЦ» | Учёт остатков на временном хранении |
| АРМ «Учёт временного хранения» | Рабочее место кладовщика |
| Отчёт «ТМЦ на временном хранении» | Контроль ТМЦ на складе |
| Личная карточка учёта выдачи СИЗ | Печатная форма истории выдачи и возврата |
