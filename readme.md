# Автоматизация согласования заказов поставщикам в 1С:ERP

## Описание проекта

Проект направлен на усиление контроля закупок за счёт автоматизации
согласования заказов поставщикам в системе 1С:ERP.

Разработано решение, которое обеспечивает последовательное согласование
заказа по заданному маршруту, учитывает сумму документа при подключении
дополнительного согласующего, фиксирует решения участников и исключает
дальнейшую работу с несогласованными заказами.

## Бизнес-задача

В процессе закупок требовалось исключить риск оформления заказов поставщикам
без необходимого контроля со стороны руководителей и финансового блока.

Целевое решение должно обеспечивать:

- обязательное согласование заказов поставщикам;
- последовательный маршрут согласования;
- подключение директора по закупкам для заказов свыше установленного порога;
- контроль статуса заказа после завершения процесса;
- уведомления участников о назначении и выполнении задач;
- возможность просмотра истории и результатов согласования.

## Участники процесса

| Роль | Ответственность |
|---|---|
| Инициатор | Создаёт заказ поставщику и инициирует согласование |
| Руководитель инициатора | Выполняет первичное согласование заказа |
| Директор по закупкам | Согласовывает заказы, сумма которых превышает установленный порог |
| Финансовый контролёр | Выполняет финальное согласование заказа |
| Администратор системы | Настраивает роли, исполнителей, параметры и права доступа |

## Логика решения

1. При проведении заказа поставщику система автоматически запускает процесс согласования.
2. Перед запуском система проверяет отсутствие активного процесса по этому заказу.
3. Заказ последовательно согласуют руководитель инициатора и финансовый контролёр.
4. Если сумма заказа превышает установленный порог, в маршрут включается директор по закупкам.
5. При отказе любого участника процесс завершается со статусом «Не согласовано», а инициатор получает уведомление.
6. После успешного согласования всеми участниками заказ получает статус «Согласован».
7. Пользователи могут просматривать назначенные задачи, детали заказа, маршрут процесса и отчёт по согласованию.

## Проектное решение

Для реализации решения предусмотрено использование типовых механизмов
1С:ERP и разработка дополнительных объектов.

| Объект | Назначение | Вариант реализации |
|---|---|---|
| Бизнес-процесс «Согласование заказа поставщику» | Маршрутизация и контроль последовательного согласования | Доработка |
| Задачи бизнес-процесса | Назначение задач согласующим и фиксация решений | Типовой механизм с адаптацией |
| Роли исполнителей | Определение участников маршрута | Типовой механизм |
| Регистр сведений «Исполнители задач» | Связь ролей с пользователями системы | Типовой механизм |
| Регистр «Порог суммы для согласования заказов поставщикам» | Хранение порога для подключения директора по закупкам | Новый объект |
| Обработка «Согласование заказов поставщикам» | Рабочее место согласующего для просмотра и выполнения задач | Новый объект |
| Отчёт по согласованию | Просмотр маршрута, участников и результатов согласования | Доработка |
