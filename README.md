В репозитории собраны проекты по бизнес-анализу и автоматизации учётных процессов в 1С:ERP. Портфолио включает кейсы по закупкам, согласованию заказов поставщикам, складскому учёту, контролю ТМЦ и оптимизации бизнес-процессов. В проектах представлены BPMN-схемы AS-IS / TO-BE, бизнес- и функциональные требования, реестры требований, частные технические задания, описание проектных решений, тест-кейсы, матрицы прав доступа, инструкции администратора и рекомендации по реализации доработок.
