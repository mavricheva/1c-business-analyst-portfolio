Подготовка документации для внедрения 1С:ERP

## Описание проекта

Проект по подготовке комплекта документации для внедрения 1С:ERP.

## Моя роль

Бизнес-аналитик / специалист по документации 1С.

- Подготовила чек-лист первоначальной настройки.
- Описала порядок заполнения справочников и ввода остатков.
- Подготовила инструкцию администратора (развёртывание базы, ордерный склад).
- Разработала инструкцию пользователя (ПТиУ, кассовый ордер).
- Подготовила программу и методику испытаний, сценарий приёмочного тестирования.

## Основные процессы

- Настройка общих параметров, справочников, видов цен и цен номенклатуры.
- Перенос сотрудников, контрагентов, номенклатуры, начальных остатков.
- Настройка пользователей, ролей и прав доступа.
- Сценарий сквозного процесса: Предварительная запись → Реализация → ПКО → Печать → Отчёты.
